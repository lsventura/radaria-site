# Bipac — 200 ícones SVG de relevo 3D

Esta biblioteca contém **200 arquivos individuais SVG**, com fundo transparente, cores do Bipac, gradientes, extrusão leve e sombra; criados a partir dos ícones Lucide já aprovados para o portal. O Bipo continua **minimalista 2D**.

**Importante:** são **adaptações vetoriais 2.5D**, não arquivos 3D modelados, PNGs originais ou recortes idênticos às pranchas 3D geradas em conversa. As pranchas são referências conceituais. Para copiar fielmente o realismo dessas pranchas seria necessário reconstruir 200 objetos individualmente.

## Como usar

- Ícones: `/brand/bipac/3d/icones/bipac-3d-001-inicio.svg` etc.
- Manifesto para agentes: `manifest.json` com 200 slugs, categorias e caminhos.
- Galeria: abra `catalogo-3d.html` para prévia, busca e download.
- Deixe ícones de navegação e botões pequenos com a versão 2D de `../icones/`, preferindo 3D nos cards de departamentos, destaques, heróis e vitrines de ofertas.
- Tamanho sugerido de exibição: 40–96 CSS px; testar contraste, legibilidade e performance no mobile antes de integrar.
- Não substituir automaticamente as referências antigas; não trocar a marca pública **Bipeque** no código sem tarefa específica.
